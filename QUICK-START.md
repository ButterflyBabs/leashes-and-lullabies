## 🎯 Fastest Path to Live (Netlify)

### Step 1: Get Files (1 minute)
The website is ready at:
```
~/.openclaw/workspace/leashes-and-lullabies/
```

Download or have access to:
- index.html
- styles.css
- script.js

### Step 2: Create Netlify Account (2 minutes)
1. Go to https://netlify.com
2. Click "Sign up"
3. Use email or GitHub login
4. Verify email

### Step 3: Deploy Website (2 minutes)
1. Click "Add new site" → "Deploy manually"
2. Drag the entire `leashes-and-lullabies` folder into the drop zone
3. Wait 30 seconds for deployment
4. 🎉 Your site is live!

**You'll get a free URL like:**  
`https://random-name-12345.netlify.app`

### Step 4: Set Up Contact Form (5 minutes)
1. In Netlify dashboard, click your site
2. Go to "Forms" in left sidebar
3. Click "Enable form detection"
4. In `index.html`, add `netlify` to the form tag:
```html
<form netlify class="contact-form" id="contactForm">
```
5. Re-upload the file or push to GitHub
6. Go to Forms → Settings → Form notifications
7. Add parent's email address

### Step 5: Test Everything (5 minutes)
- [ ] Open site on phone
- [ ] Click every button
- [ ] Submit test form
- [ ] Check parent email receives form
- [ ] Test click-to-call phone link
- [ ] Try mobile menu

### Step 6: Custom Domain (Optional - 10 minutes)
1. Buy domain (namecheap.com or similar)
   - Suggested: `leashesandlullabies.com`
2. In Netlify: Domain settings → Add custom domain
3. Follow DNS setup instructions
4. Wait 24-48 hours for DNS propagation
5. Free SSL certificate auto-installs

**Done! Your site is live! 🚀**

## 🆘 Common Issues

**Form not working?**
- Make sure you added `netlify` to form tag
- Check email settings in Netlify dashboard
- Look in spam folder

**Site not loading?**
- Clear browser cache
- Try incognito/private mode
- Check Netlify deploy log for errors

**Mobile menu stuck?**
- Refresh page
- Check JavaScript console for errors
- Verify script.js is loading
